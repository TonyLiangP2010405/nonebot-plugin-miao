# nonebot-plugin-miao

原神 / 崩坏：星穹铁道的 NoneBot2 抽卡记录与角色面板插件，并提供原神、星铁、绝区零的模拟抽卡与角色攻略图。移植自 [miao-plugin](https://github.com/yoimiya-kokomi/miao-plugin)（MIT），支持 OneBot V11。

## 功能

- Authkey 抽卡记录更新、分析、按版本统计、UIGF / SRGF 导入导出
- 原神、星铁、绝区零模拟单抽/十连、多角色池与装备池选择、保底、原神武器定轨和每日次数限制
- 三游戏国服卡池从官方公开接口自动同步，按开放时间切换，无需绑定 UID 或 Cookie
- Enka（原神）、Mihomo（星铁）、米游社 Cookie 面板更新
- 属性计算、圣遗物 / 遗器评分、面板列表 / 详情 / 伤害图片，更新面板后返回图片回执；群面板排名（单角色榜 / 群友综合榜）同样出图
- 角色名支持官方名、常用别名/外号与常见错字（含同音字；如 `优拉`→优菈、`芙琳娜`→芙宁娜、`神里凌华`→神里绫华、`流莹`→流萤、`镜琉`→镜流），面板、排名、图鉴、攻略指令通用
- 星铁「加强角色」兼容：mihomo 把流萤等加强角色解析为 `流萤Pro` 时，`/流萤面板` 会自动回落到加强版数据，`/流萤Pro面板` 也可用；详情卡补全 100% 基础充能与击破特攻等 10 项属性
- 可选与 [nonebot-plugin-mantou-affection](https://github.com/TonyLiangP2010405/nonebot-plugin-mantou-affection) 联动，用转盘抽到的面板 / 群排名次数或好感度查看；详情卡包含角色立绘、天赋等级、命座图标、属性权重、武器精炼与被动、逐件圣遗物主副词条 / 强化次数 / 单件评分、星铁行迹矩阵、伤害表、词条替换热力表与 Buff 列表
- 原神角色与武器图鉴、名称索引（无需绑定 UID）
- 原神、星铁与绝区零角色攻略图（分游戏来源、本地缓存、强制刷新与默认来源设置）

## 安装

```bash
nb plugin install nonebot-plugin-miao-genshin
pip install nonebot-plugin-miao-genshin
poetry add nonebot-plugin-miao-genshin
```

> 注意：PyPI 上的 `nonebot-plugin-miao` 是他人发布的无关项目，请勿安装；本插件的 PyPI 包名为 `nonebot-plugin-miao-genshin`（导入模块名仍为 `nonebot_plugin_miao`）。

## 配置

均有默认值；在 NoneBot `.env` 中按需覆盖。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `MIAO_RES_MIRROR` | jsDelivr miao-plugin resources | 角色图片与静态资源镜像 |
| `MIAO_PROFILE_INTERVAL` | `3` | 面板更新冷却（分钟） |
| `MIAO_MYS_COOKIE` | 空 | 全局米游社 Cookie（可选） |
| `MIAO_GACHA_DAILY_LIMIT` | `1` | 每款游戏每日模拟额度，1 代表 10 抽；同游戏所有卡池合计，SUPERUSER 不限 |
| `MIAO_GACHA_POOL_INTERVAL` | `60` | 官方模拟卡池同步间隔（分钟，至少 1）；查看/抽取时按需检查，后台每 5 分钟检查是否到期 |
| `MIAO_RES_AUTO_UPDATE` | `True` | 每日自动更新面板资源（凌晨 4:20，需 nonebot-plugin-apscheduler） |
| `MIAO_PANEL_ENABLED` | `True` | 面板功能总开关；SUPERUSER 也可用 `/面板开关` 运行时切换 |
| `MIAO_PANEL_UPDATE_INTERVAL` | `60` | `/更新面板`、`/米游社更新面板` 的命令冷却（分钟，原神/星铁分别计算；0 表示不限制） |
| `MIAO_PANEL_OPEN_HOUR` | `8` | 面板每天开放时间（整点，Asia/Shanghai） |
| `MIAO_PANEL_CLOSE_HOUR` | `17` | 面板每天关闭时间（整点）；与开启时间相同表示全天 |
| `MIAO_PANEL_FREE_PER_HOUR` | `1` | 角色面板 / 群排名各自每小时的免费次数 |
| `MIAO_PANEL_USER_HOURLY_LIMIT` | `2` | 角色面板 / 群排名各自每小时最多查看次数（含免费与付费；转盘次数不占额度、不受开放时段限制） |
| `MIAO_PANEL_AFFECTION_COST` | `10` | 免费次数用完后每次查看消耗的好感度（0 表示不允许用好感度抵扣） |
| `MIAO_PANEL_OFFHOUR_AFFECTION_COST` | `50` | 非开放时段每次查看消耗的好感度（0 表示非开放时段不可用；转盘次数仍然优先） |
| `MIAO_PANEL_NOTIFY_ENABLED` | `True` | 面板开放 / 关闭时在群里提醒（只发用过面板指令的群） |
| `MIAO_PANEL_NOTIFY_REPEAT` | `3` | 每次提醒连发几遍（1-5） |
| `MIAO_PANEL_CONFIRM_TIMEOUT` | `30` | 付费查看确认的有效秒数，支持回复「确认」或发送 `/面板确认` |
| `MIAO_STRATEGY_DEFAULT_SOURCE` | `1` | 原神角色攻略图默认来源（1-7，可被设置指令覆盖） |
| `MIAO_SR_STRATEGY_DEFAULT_SOURCE` | `1` | 星铁角色攻略图默认来源（1-3，可被设置指令覆盖） |
| `MIAO_ZZZ_STRATEGY_DEFAULT_SOURCE` | `1` | 绝区零角色攻略图默认来源（1-4，可被设置指令覆盖） |

### 三游戏模拟抽卡

- 默认不带游戏名为原神。`十连`、`十抽`、`10连`、`10抽` 均可；换成 `单抽` 就只扣除 1 抽并推进 1 次保底。模拟指令兼容 `/`、`#` 前缀。
- 角色池与装备池分别编号。例如 `星铁十连2` 抽第二个角色池，`星铁光锥十连2` 抽第二个光锥池；`绝区零音擎十连2` 抽第二个音擎池。以当前卡池列表为准，不存在的编号会提示，不会消耗次数。
- 常驻池：`常驻十连`、`星铁常驻十连`、`绝区零常驻十连`。星铁联动角色/光锥池也会列出，并与普通活动池分别保存保底。
- 三款游戏分别保存保底和每日额度。同游戏普通角色活动池之间共享保底，装备池之间共享另一份保底，常驻池独立；群聊和私聊沿用各自的用户存档。每日北京时间 04:00 重置额度，保底不清零。
- 原神旧存档保留累计抽数和大小保底。武器命定值上限为 1；换期清空定轨及命定值，保留武器大小保底。旧存档无法确认定轨所属期次时，也会清空定轨及命定值。

卡池使用官方国服公开数据：[原神](https://operation-webstatic.mihoyo.com/gacha_info/hk4e/cn_gf01/gacha/list.json)、[星铁](https://operation-webstatic.mihoyo.com/gacha_info/hkrpg/prod_gf_cn/gacha/list.json)、[绝区零](https://operation-webstatic.mihoyo.com/gacha_info/nap/prod_gf_cn/gacha/list.json)。每次同步读取全部受支持卡池的中文详情，更新 UP、陪跑四星、常驻物品和基础概率；新角色不依赖插件内置角色表。结果优先使用官方提供的图片，缺图时显示名字占位卡。

首次使用联网获取并持久化缓存，此后按配置自动同步。后台每 5 分钟检查；查看或抽取时也检查同步期限及开池/结束时间，所以机器人重启后仍可自动恢复。自动同步独立于 `MIAO_RES_AUTO_UPDATE`。接口故障只使用仍有效的旧缓存并提示，过期或尚未开放的池不会参与抽取，失败后至少间隔 1 分钟重试。

模拟器实现基础概率、90 抽角色/常驻保底、80 抽装备保底、四星保底、大小保底及原神武器定轨；软保底使用模拟递增曲线。目前不模拟原神捕获明光、常驻新手优惠/自选奖励、星铁「星缘相邀」或绝区零「定制调频」自选名单，也不包含集录、新手专池和邦布池。上述自选名单按未自定义时的官方默认物品表处理。

攻略来源编号按游戏分别计算：

- 原神：1 西风驿站、2 原神观测枢、3 派蒙喵喵屋、4 OH是姜姜呀、5 曉K、6 坤易、7 婧枫赛赛。
- 星铁：1 列车广播、2 牧牧Muu、3 丶ATRI丶。
- 绝区零：1 绳么东西BROADCAST、2 烟雨如诗、3 丶ATRI丶、4 小橙子阿。

攻略数据来自米游社公开合集，新域名不可用时会自动尝试旧域名。星铁和绝区零会继续进入合集链接的具体攻略帖，排除文章封面后返回正文攻略图；接口不可用或对应来源未收录角色时，插件会返回中文提示。绝区零目前没有随包角色元数据，指令直接按正式角色名匹配，因此新角色无需等待插件更新，但不保证识别简称。

### 面板总开关

发送 `/面板开关 关` 会立即停用所有面板指令（更新、列表、详情、伤害、圣遗物列表、面板次数、付费确认），
`/面板开关 开` 恢复，`/面板开关 重置` 清除运行时覆盖、回到 `MIAO_PANEL_ENABLED` 配置值。
开关状态持久保存，重启后仍然生效；仅 SUPERUSER 可操作。

### 面板开放时间

面板功能默认每天 **08:00–17:00**（Asia/Shanghai）开放，`/面板开关` 与 `/面板次数` 不受时段限制。
转盘抽到的**角色面板次数 / 群面板排名次数不受开放时段限制**，任何时间都可以直接使用。
非开放时段也支持用好感度查看：每次消耗 **50 点好感度**（`MIAO_PANEL_OFFHOUR_AFFECTION_COST`，设为 0 则关闭），
回复「确认」或发送 `/面板确认` 后扣费，不占用免费额度与每小时上限；私聊没有群好感度账本，非开放时段仍然关闭。
面板**开启 / 关闭**时会在用过面板指令的群里提醒，默认**连发 3 遍**（`MIAO_PANEL_NOTIFY_REPEAT`），
可用 `MIAO_PANEL_NOTIFY_ENABLED` 关闭。
可通过 `MIAO_PANEL_OPEN_HOUR` / `MIAO_PANEL_CLOSE_HOUR` 修改；两者相同表示全天开放，也支持跨天时段。

`/更新面板` 与 `/米游社更新面板` 另有一小时一次的硬限制：同一 QQ 在同一游戏内，成功更新后
`MIAO_PANEL_UPDATE_INTERVAL`（默认 60 分钟）内不能再次更新；原神与星铁分别计时，改成 `0` 可关闭该限制。
开放时段更新免费。非开放时段，群友更新成功消耗 1 次角色面板次数，数据更新失败会返还次数。
SUPERUSER 在群里可以随时代群友更新或查看。代更新走 Enka 或 Mihomo，并按被 @ 群友的更新冷却计时。

### 面板次数与馒头好感度联动

安装并加载 `nonebot-plugin-mantou-affection`（建议 0.44.0 及以上，群排名次数需要新版）后自动启用；
未安装时面板功能保持免费、不限次数：

- 馒头命运齿轮转盘：
  - **5%** 概率抽到「角色面板次数 ×1」；
  - **3%** 概率抽到「群面板排名次数 ×1」，这 3% 从原「主动戳一戳」概率中划出；
- 群聊每人每小时，**角色面板**和**群面板排名**各自独立计算：
  - 前 **1 次免费**；
  - 最多查看 **2 次**；
  - 免费次数用完后，第 2 次消耗 **10 点好感度**，需要回复「确认」才会扣费出图；
- 转盘抽到的对应次数**优先消耗**，**不占用免费额度，也不计入每小时 2 次上限**；
- 转盘次数**不受面板开放时段限制**：即使当前不在 08:00–17:00，只要对应次数还有剩余就能查看；
- **非开放时段**：没有转盘次数时，每次查看消耗 **50 点好感度**（默认，可配置），需回复「确认」后扣费；不占免费额度与每小时上限；
- 私聊查看免费（仅开放时段），不消耗次数；
- SUPERUSER 免费、不限次数，也不占用额度；
- `/绑定uid`、`/面板列表`、`/圣遗物列表` 不消耗面板次数；
- `/面板次数` 可以查看开放时间、两类转盘次数、免费剩余、本小时额度和好感度。

SUPERUSER 可以在群里用 `/面板次数调整 @群友 +2` 赠送角色面板次数，或用 `/群面板排名次数调整 @群友 -1` 扣除群排名次数。两条指令都支持增减，单次调整 1–9999 次。调整与转盘奖励使用同一余额，赠送的次数同样可以在非开放时段使用。余额不足时整笔扣除失败。
